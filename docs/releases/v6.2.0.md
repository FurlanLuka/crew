# v6.2.0: Voice OS redesigned

Voice OS got redesigned. Home shows your sessions with whatever waits on you first, and an
**Answer** button right there. Each machine gets a card and its own page, with its plain sessions and
its worktrees by workspace. The old "+" is a **New** menu, there's a proper New session dialog that
remembers the folders you've used, and Settings is laid out like a page you'd actually want to read,
including a Voice section to turn voice on and off.

I also dropped the language picker. It turns out Soniox detects the language on its own and the hints
only nudged it, so now you just speak whatever you speak, switching mid-sentence included. And after
a dev push, a main on a real release now updates remotes still sitting on the dev build, the same way
it updates ones that are behind. The crew title also plays once per page load instead of every time
you go back to Home.
