# v6.8.0: A context meter by the text box

Right of a session's text box there's now a meter that says how full its context is, "42k / 200k"
of the model's window. It turns amber as Claude Code gets close to compacting on its own and red just
before it does, and hovering it gives the exact numbers and where Claude Code will compact. It
updates after every turn, a compaction or a clear, and it comes back after a remote machine
reconnects.

Tap it for **Compact**, which summarizes the conversation so far, or **Clear**, which starts a fresh
one. Both go to the session as `/compact` and `/clear`, so Voice OS asks you to confirm first, the
same as when you type them.
