# v6.7.0: Permission modes per session

Every session now has a permission mode, and you can switch it whenever you like. A chip left of the
session's text box shows the mode; tap it and pick another. You can also type `/mode plan`, or say
"switch to plan mode" or "put checkout in ask mode". The session switches at once and keeps the mode
until you change it, across restarts too.

There are four: **Auto**, the default, where Claude Code's classifier lets routine work run and
blocks what looks risky; **Plan**, where it plans and changes nothing; **Ask**, where every permission
comes to you as a card; and **Skip**, which runs everything with no checks. Approving a plan puts the
session back in the mode it had before Plan. Skip asks first when you say it aloud ("Skip permissions
for checkout?"), shows **skip** on the session's tab and in Active, and is refused on a machine where
Claude Code runs as root, since Claude Code won't run it there. Questions and plans come to you in
every mode.
