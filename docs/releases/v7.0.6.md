# v7.0.6: Every model Claude Code offers

The model chip beside the text box used to offer three models written into Voice OS. Its menu is
now the list the session's own Claude Code offers your account, with Claude Code's names and
descriptions, so Fable 5.1 and Fable 5.2 are there today, and the next model shows up without a
Voice OS release. The chip says the model a session runs on and checks its row; picking
**Default** goes back to Claude Code's own default.

A session on a remote machine keeps its model on the chip after the link reconnects. Until now the chip
went missing until the session started again.

The Agent SDK under every session is 0.3.322, up from 0.3.282.
