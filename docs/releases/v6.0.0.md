# crew 6.0.0

crew moves to the browser. Run bare `crew` and it starts crew's server and opens its page, or prints
the link when you're over SSH. The page opens on Home, where you pick Voice OS or Set up. Set up does
everything the configuration TUIs used to do (projects, workspaces, worktrees, bindings, machines,
settings, import and export) and every form shows the crew command it runs. There's a Setup with
Claude chat in there too, and a first run that walks you from picking projects to a working
workspace. Voice OS got a restyle to match, with a docked top bar, tabs for your active sessions and
a layout that works on a phone.

The terminal keeps exactly one interactive thing, launching Claude (`crew launch`, `crew <ref>`).
The workspace, project, settings, import/export and debug TUIs are gone. `crew workspace` and
`crew project` now print the list and point you at the page. To back the page, a bunch of commands
got non-interactive forms, like `add project --scan`, `add binding --dry-run`, `rm worktree --dry-run`,
`ls bases`, `export -` and `import -`.

## Upgrading

```bash
crew update
crew
```

`crew voice …` now lives under `crew server …` (`start`, `stop`, `restart`, `logs`, `remote`, `keys`,
`machines`, `discord` and the rest). `crew voice` keeps working as an alias and always will, so
scripts and older machines are fine. The server runs in a tmux session called `crew-server` now,
which means `crew dev stop` and `crew kill` leave it alone. The Claude Code plugin is 6.0.0 as well.
