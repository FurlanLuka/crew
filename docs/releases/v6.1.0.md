# crew 6.1.0

A lot landed in this one. The part you'll notice first is that Voice OS feels like someone is there.
When you say something that goes to the router, you get a quick "Okay" or "Got it" while it thinks.
The follow-ups ("Sent to checkout", "Switching to store-front") are worded for the moment by Haiku,
and while the session on screen works for a long stretch, you hear a short line about what it's doing
now and then. If you lose track, "status update" gets you a spoken recap: what waits on you, what got
done, what's still running. Speak to a busy session and it says "Okay, after its current work. Send
it now?", and a yes sends your words right away.

There are also new kinds of sessions and new places to reach them. You can start a plain Claude
session in any folder on any machine, with no crew context, from the page (**New session**), by voice,
or with `crew chat add`. Sessions can post to your Discord when you ask ("send that screenshot to
Discord"), from the main or any remote, and the bot token never leaves the main. Clicking a
sub-agent opens its transcript as it runs. And one click on **voice** in the top bar turns all voice
off: nothing listens, nothing speaks, the Discord bot leaves its channel, and the page keeps working.

On the setup side, the first run is now one full-screen flow on Home: pick your projects, name a
workspace, watch its main worktree get made, then go to Voice OS. Export and import are guided pages
too. Import asks every question up front, and `crew import --plan` now spots when you already have a
checkout of a repo (`found`), so the page offers to use yours instead of cloning it again. The README
got a rewrite, a batch of debug notes got fixed, and reloading Home no longer flashes a
"Connecting…" card.

One thing to know: `chat` is now a reserved workspace name. An existing workspace called that keeps
working, you just can't make a new one with that name.
