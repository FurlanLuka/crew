# crew 5.4.0

Debugging Voice OS used to mean grepping a 100 MB log and running `jq` over the debug notes, with no
way to see another machine's log at all. Now `crew voice logs` takes filters (`--since`, `--until`,
`--cat`, `--level`, `--grep`, `--machine`, `--lines`, `--json`) and reads every machine at once,
and there's `crew voice debug-notes` and `crew voice notes` next to it. Any machine can ask: a remote
goes through the main over its link, and if there's no main it shows its own logs and says why. The
log rotates now too, 20 MB across five files.

I also fixed the meanwhile line getting cut off a fraction of a second after it started, and after
the router tells you about another session, your reply to that offers "Switch there?" like any other
update does.

## Upgrading

Run this once on each remote machine so its daemon opens the new query socket:

```bash
crew update
crew voice remote
```
