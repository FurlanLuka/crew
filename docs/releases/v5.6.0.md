# v5.6.0: Fixes from my debug notes

Mostly fixes from my own debug notes. Voice OS now tells you when the session you're on starts
compacting, so the long pause makes sense. Words you said on one screen stay with that session if you
click away before they're sent. A bare "no" to "Switch there?" just closes it. "Can you approve?"
approves. "Go back to checkout" goes to checkout. Your own session names win over a worktree that
sounds the same, and a remote that reconnects after a night asleep says it's back only if something
actually happened.

"Show me the diff" on a session's screen used to go looking for a doc called that, find nothing and
ask what it's called. Now it goes to the session. I also cleared out a dozen near-duplicate kernel
eval cases.
