# v6.5.1: Crew with a capital C

A small one. The site's page titles, crew's own page in the browser tab and both favicons now say
Crew with a capital C. The command is still `crew`.

session") instead of the bare tag, the old ones included, and a pull request that only touches docs
no longer waits forever on checks that never run.
