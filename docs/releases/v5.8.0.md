# crew 5.8.0

You can talk to Voice OS from your phone now, through Discord. A bot sits in a voice channel on your
own Discord server, and joining it is like opening the page and talking. It only listens to the
server owner, so anyone else in the channel is never heard, and the call is end-to-end encrypted.
While you're in the channel the page shows "Voice via Discord", the listening menu sets Discord's mode,
and sessions are told you can hear them but can't see the page.

To set it up, make a bot in Discord, then hand crew its token:

```bash
crew update
crew voice discord setup    # paste the bot token
```

It works out your server and channel from the token and checks the bot has the permissions it
needs. `crew voice discord status` and `crew voice discord off` do what they say. While testing this
I also found a session that crashed with your words waiting just went quiet; now it says it couldn't
run and that your words are kept for the next start.
