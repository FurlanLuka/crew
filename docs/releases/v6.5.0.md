# v6.5.0: A / menu in every session

Type `/` in a session's box and you get a menu of that session's commands, the same list Claude Code
has: its built-in commands that work here, your project and user commands, skills and plugin
commands, each with what it does. Pick one, add what it should work on, and it goes to the session
as words. Skills you add while it works show up without a restart. It works in Set up's chat too.

Below Claude's commands are a few of Voice OS's own, which run on the page instead of going to
Claude: `/reload-plugins` and `/reload-skills` for that session, `/model` to switch its model for the
next turn, `/stop`, `/mute` and `/unmute`, `/voice off` and `/voice on`, and `/update` and `/restart`.
`/update` always updates the main machine, whichever session's box you type it in, says when crew is
already current, and only offers a restart when it installed something. It never restarts by itself.

crew is MIT licensed again. The source-available license didn't protect anything worth the friction
it caused.

There's also a site now, getcrew.sh, built from the docs and the release notes, and the README and
docs have current screenshots and a picture for every main flow.
