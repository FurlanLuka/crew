# crew 6.3.0: Hand a session files

You can hand a session files now. Paste a screenshot, drop a log anywhere on the session's page, or
use the paperclip, in Voice OS and in Set up's chat. Each file shows as a chip above the box, and the
next words that reach that session take them along, typed or spoken, even if you say them from
another screen ("Sent to checkout with 2 files."). Claude gets each one as a path and opens it with
Read, so any file up to 20 MB works. Sessions on a remote machine get the bytes sent over first, and
an upload cut by a dropped link picks up after the reconnect.

You can also reorder your session tabs by dragging them, or with Alt+← and Alt+→, and the order sticks
across restarts. The "auto mode blocked …" prompt now sits above the text box with the other asks,
where you'd look for it.
