# crew 5.9.0: Active sessions replace pinned ones

Pinned is gone, and active sessions take its place. Only an active session exists as far as voice is
concerned: its Claude runs and you can talk to it. Inactive ones have no process and say nothing, and
you browse them on the page and activate them there or by voice ("activate checkout"). Words for an
inactive session wait in its queue behind "checkout isn't active. Activate it?". This keeps the
router's world small, and it means you're only paying for the sessions you're actually using. Your
pins carry over as your active set the first time you start, so there's nothing to do.

There's also `crew voice dev push`, mostly for me. Run it from a checkout on any machine and it builds
crew and Voice OS for every machine you have, installs the build everywhere and restarts them all,
the one you ran it from last. `crew voice dev status` follows along.
