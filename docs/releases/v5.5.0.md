# v5.5.0: Sessions that need you wait their turn

When another session needs you, a permission or a question or a plan, it no longer barges in on its
own. It waits a breath and comes in the meanwhile line, needs-you first, with the chime:
"Meanwhile, checkout wants to run git push." Short asks are said in full and you can answer them from
wherever you are. Long questions and plans come as a gist, and a bare yes to a gist asks whether to
switch there, so you never approve something you only half heard.

Also, follow-ups to a note you just took ("check the latest debug note, then fix it", "send this note
to checkout") now go to the session with the note attached, instead of turning into another note.
