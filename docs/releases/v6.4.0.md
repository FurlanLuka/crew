# crew 6.4.0: Dev server logs from the session page

Every dev server row on a session's page now has a logs button. It opens the server's log in a window
with a tab per server, follows it every two seconds, marks error lines in red and leaves you alone
when you scroll up to read. It works for remote sessions too, and there's a button to restart the dev
servers from there.

This also fixes something nasty. Two of my sessions lost their whole history when their Claude
processes got killed while one was still reopening its conversation, and Voice OS took that as "the
conversation is gone" and started a fresh one. Now it only starts fresh when Claude itself says the
conversation doesn't exist. A kill or crash is just a crash, and the next start picks up where it was.
