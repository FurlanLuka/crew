# v7.0.1: The phone keeps up with your thumb

Two fixes for Voice OS on a phone.

Going back is instant. After a swipe back, the phone used to sit still for about a second before
Home would scroll: it waited for the server to confirm the new screen, then slid Home in a second
time. Now every screen change on the phone shows at once and the server catches up behind it. A
swipe's back doesn't slide again, and Home underneath follows your finger as you drag, from dimmed
and set back to fully in place. If the server goes somewhere else in the meantime, from voice or
another tab, its screen wins.

The history fits the screen. A long path, a table or a long line of code used to push the whole
conversation past the phone's edge, where it couldn't be scrolled. The history now keeps to the
screen's width, tables and code blocks scroll sideways inside their own box, and table cells only
break between words.
